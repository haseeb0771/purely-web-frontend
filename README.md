# Purely — Custom Labels

A modern single-page website for **Purely**, a purveyor of lab-tested RO-filtered mineral water and custom white-label bottled water for corporate events, weddings, hotels, and retail brands.

![Purely](public/logo.png)

## Features

- **Hero** — brand-first landing section with certifications CTA, custom quote CTA, trust markers, and a live stats strip (happy clients, bottles delivered, custom sizes, support).
- **About** — dual offerings: Purely branded water and custom labeled packaging, plus production/lab/logistics highlights.
- **Certifications** — PSQCA approval, ISO 9001 quality, 7-stage RO purification, and daily lab verification.
- **Custom Services** — client use-cases and available bottle formats (300ml, 500ml, 1.5L, 19L).
- **Contact** — inquiry form, phone/email contact cards, Instagram/TikTok links, and a QR card.
- **Light & Dark themes** — theme toggle in the navbar, defaulting to light, with a dedicated dark logo.
- **Fully responsive** — optimized grids and layouts across mobile, tablet, and desktop.
- **Smooth scrolling** — animated in-view reveals and smooth anchor navigation between sections.

## Tech Stack

- **Next.js 15** (App Router) with static generation
- **TypeScript**
- **Tailwind CSS v3** with class-based dark mode
- **Framer Motion** animations
- **Lucide icons** + custom social icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build & Lint

```bash
npm run build
npm run lint
```
